Documentation

Ultimate Client Manager

A self hosted CRM, quoting, invoicing and job tracking system that runs on ordinary PHP and MySQL hosting. No monthly fee, no external service, and your data stays in your own database.

This documentation ships inside the download. It assumes no programming knowledge for installing and running the software, and gets more technical only in the last few pages, which are for people who want to change how it works.

If you are updating an existing installation

Do not upload these files over the top of a working site until you have read Upgrading from 2.x. This release raises the minimum PHP version and changes where database settings are stored. Both of those will stop an old installation from loading if you skip the steps.

What the software does

Ultimate Client Manager is built as a set of plugins around a small core. Each area of the product is a plugin, which is why the feature list is long and why you can switch parts of it off. The main areas are:

AreaWhat it covers
Customers and contactsCompanies, the people at them, addresses, custom fields, customer types such as leads and suppliers, and a customer portal those contacts can log into.
Quotes and contractsQuotes built from your product list, sent for approval, and signed off online with a drawn signature.
Jobs and tasksJobs broken into tasks, assigned to staff, with a discussion thread per job and a change request workflow.
Invoices and paymentsInvoices, credit notes, recurring subscriptions, tax handling, multiple currencies, and online payment through the gateways described in Payment methods.
Time trackingA timer that attaches recorded time to a job or task and carries it through to an invoice.
Support ticketsA ticket queue that can collect replies from an email mailbox and file them against the right ticket.
FinanceIncome and expense transactions, recurring entries, and summary reporting.
Email and newslettersTemplated transactional email, plus a bulk newsletter sender with its own subscriber lists.
Files and dataFile uploads attached to records, and a general purpose structured data store for things the product does not model directly.
Staff and permissionsStaff accounts, roles, and per-feature permissions.

Sixty five plugins ship in total. The plugin system lists every one of them with its version, and explains how they fit together.

How the documentation is arranged

  • Getting started takes you from a fresh hosting account to a working login, or from an existing 2.x installation to this release.
  • Running it covers the settings you will touch after installing: configuration values, the scheduled task that drives recurring work, and connecting a payment gateway.
  • Making it yours explains the plugin architecture and the custom/ folder, which lets you change almost any screen or template without editing the files you were shipped — so your changes survive the next update.
  • Reference holds the troubleshooting guide, what changed in this release, and the credits and licences for the third party code included in the download.

Getting help

Support is through the item’s comments page on CodeCanyon. Before posting, it is worth checking Troubleshooting — it covers the problems that come up most often, and in most cases tells you exactly which setting or file permission is at fault.

If you report a problem, say which PHP version your host runs, whether the site is on Apache or nginx, and what the page did — a blank screen, an error message, or the wrong result. Those three answers resolve most reports immediately.
