Ultimate Client Manager

Getting started with version 4.0.0. This page covers installing and upgrading. Everything else is in the full documentation at ultimateclientmanager.com/docs, which is kept up to date with each release.

What you need

  • PHP 8.2 or newer, with the mysqli extension. PHP 8.3 or newer is recommended.
  • MySQL 8 or MariaDB 10.5 or newer, with an empty database. The database user needs permission to create and alter tables.
  • HTTPS, so sign-in cookies are kept secure.

The requirements page has the full list.

Installing

  1. Unzip the download. Upload everything inside the Main Files folder to your web space, either the site root or a subfolder. The Documentation and Licensing folders are for you to read and do not need uploading.
  2. Create an empty database and a database user in your hosting control panel.
  3. Open the address you uploaded to in a browser. The setup wizard asks for the database details, creates the tables, and saves your settings in includes/config.local.php.
  4. Sign in as the administrator, admin@example.com, with the password password. You are asked to choose a new password straight away. The other sample accounts have no password and cannot sign in until you give them one, or you can delete them.
  5. Set up the scheduled task, so invoices, renewals and reminders go out on time. See scheduled tasks.

Step-by-step instructions with screenshots are in the installation guide.

Upgrading from an earlier version

  1. Back up your files and your database.
  2. If your site keeps its database details in includes/config.php, move them into includes/config.local.php first. The next step replaces config.php.
  3. Upload the contents of Main Files over your existing site.
  4. Sign in, go to Settings, then Upgrade, and press Run Manual Upgrades.
This release is a large one. Read the upgrade guide before you start.

The upgrade installs newer copies of the PDF and email libraries and removes the old bundled ones. Uploading the new files does not delete anything from your site. Four payment methods that are no longer included, Authorize.Net, Coinbase, MultiSafepay and Pay.nl, stay on a site that already has them. If you do not use them, you can delete their folders (plugin_paymethod_authorize, plugin_paymethod_coinbase, plugin_paymethod_multisafepay and plugin_paymethod_paynl) from the includes folder.

What the update check sends

Nothing is sent until you press Check for Upgrades under Settings, then Upgrade. The request goes to api.ultimateclientmanager.com and contains the version of each plugin, a checksum of each plugin file, a checksum of the bundled libraries, and the licence code if you entered one. It does not contain your site address, and no customer or invoice data. Like any web request it arrives from your server's IP address, which the update server uses only to limit how often one address can ask. The update server does not use the licence code: every installation is offered the same updates, and nothing in the product stops working without one.
