Components with no licence text, and what was established about each
=====================================================================

Eight components bundled inside "Main Files" carry no licence file and no
licence header in the copy that ships. This file records, one by one, what
was established about them. It exists so the position is written down rather
than left to be guessed at from silence.

None of these is a component believed to be unlicensed in the world. Two
quite different situations are covered below and they are kept apart on
purpose, because they were resolved in different ways.


GROUP A - the licence is known upstream, the text is missing from this copy
---------------------------------------------------------------------------

For these, the upstream project has an ordinary, well known licence and the
bundled copy is simply missing the file. The remaining work is mechanical:
fetch the licence file from the upstream project at the version bundled and
drop it into this folder.

  Authorize.Net PHP SDK 1.1.8
    includes/plugin_paymethod_authorize/anet_php_1.1.8/
    Upstream shipped a LICENSE.txt with this SDK. It is not in the bundled
    copy - the directory contains only the PHP sources and a CA bundle. The
    SDK is deprecated by Authorize.Net itself.

  Coinbase PHP merchant library
    includes/plugin_paymethod_coinbase/lib/
    No header on any file. Upstream coinbase/coinbase-php was MIT. The
    bundled copy is of unclear vintage and one of its own require paths is
    already broken, so the version cannot be pinned by inspection.

  MultiSafepay Connect PHP API (2012)
    includes/plugin_paymethod_multisafepay/MultiSafepay.combined.php
    A single concatenated file with no licence header. MultiSafepay published
    this as an integration kit; the terms that applied to that distribution
    are not recorded in the file.

  MIME parser and RFC 822 address parser
    includes/plugin_ticket/cron/mime_parser.php
    includes/plugin_ticket/cron/rfc822_addresses.php
    By Manuel Lemos, distributed through phpclasses.org. The files carry a
    CVS revision header and an author name but no licence statement.

  elFinder 1.1 RC3, inside the White Label theme
    includes/plugin_theme/themes/whitelabel1/js/elfinder.js
    The upstream project is BSD-3-Clause. The bundled copy has had its
    header comment stripped, so the notice does not travel with it.

  Morris.js, inside the AdminLTE and Blocks themes
    includes/plugin_theme_adminlte/js/AdminLTE/morris.min.js
    includes/plugin_theme_blocks/js/morris.min.js
    Upstream is BSD-2-Clause. The minified copies carry no header. This one
    is listed in third-party-libraries.tsv under BSD-2-Clause rather than
    alongside the entries here, because the upstream licence is unambiguous
    and the text is included; it is noted here only so the missing header is
    on record.


GROUP B - no licence text exists; reviewed and cleared by the author
--------------------------------------------------------------------

These three carry no licence text anywhere in the bundled copy and none can
be recovered from upstream: the projects are gone, stripped, or were
obtained commercially rather than published.

The author of Ultimate Client Manager has reviewed each of them and
confirmed that they are cleared for inclusion and redistribution inside this
product.

That is what is being recorded here, and it is all that is being recorded.
No licence name is claimed for any of them, because none of them carries
one. What is stated is that the person who distributes this product has
checked the position on each component and is satisfied it is correct. If
you intend to lift any of these three out of this product and reuse it
elsewhere, that clearance does not travel with you - ask first.

  wdCalendar
    includes/plugin_calendar/wdCalendar/
    136 files. No licence file, no licence header, and no copyright notice
    anywhere in the tree except inside the copies of jQuery it bundles. The
    upstream project was hosted on Google Code, which has been shut down, so
    no licence text can be recovered. One file is packer-obfuscated, and
    several bundled sub-libraries (jQuery Validation, jQuery Form, a jQuery
    alert dialog) have had their headers stripped. This code is live: it
    renders the calendar screen.
    Reviewed and cleared by the author for inclusion in this product.

  The "White Label" admin theme by revaxarts.com
    includes/plugin_theme/themes/whitelabel1/
    859 files, around 5 MB. A commercial admin template, obtained
    commercially rather than under a published open source licence, which is
    why there is no licence file to include. It redistributes DataTables,
    elFinder, Flot, FullCalendar and a WYSIWYG editor, several with headers
    removed.
    Reviewed and cleared by the author for inclusion in this product.

  The "nsw" webfont family
    includes/plugin_theme_blocks/css/fonts/nsw{bold,light,medium}.*
    Twelve font files in four formats. No licence, no foundry name, no
    attribution and no upstream address anywhere in the tree.
    Reviewed and cleared by the author for inclusion in this product.
