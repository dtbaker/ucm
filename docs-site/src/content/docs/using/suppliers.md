These are two separate features and the naming does not help, so take them one at a time.

## Suppliers

A supplier is a [customer](/using/customers/) record with the supplier type. It is the
same record with different fields shown and its own place in the menu — so a company you
both buy from and sell to is one record, not two.

Use suppliers for the companies you buy from. Products can record which supplier they come
from, which makes a price change easy to trace through the catalogue. See
[Products](/using/products/).

## Vendors

A vendor is a grouping. It gathers staff members or suppliers together under one heading,
which is useful when you subcontract: a vendor can hold the several people who work for
one subcontracting firm, and you can see everything assigned across them.

It is a light feature and plenty of installations never use it. If it is not useful to
you, switch the plugin off in _Settings → Plugins_ and the menu goes away.
